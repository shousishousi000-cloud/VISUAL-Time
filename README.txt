ビジュアルタイマー スマホ版（Android）／通知機能つき

【公開済みのGitHubを更新する手順】
  1. GitHubの visual-timer リポジトリを開く → 「Add file」→「Upload files」
  2. このzipを解凍したフォルダの中身（7〜8ファイル全部）を画面にドラッグ → 「Commit changes」
     （同じ名前のファイルは上書きされます。badge-96.png は新しいファイルです）
  3. 1〜2分待つと反映されます。
  4. スマホで開き直します。古い画面が出る場合は、アプリを一度完全に閉じてから開いてください。
  ※ 初めて公開する場合は、前回のREADMEの手順（GitHub Pages）と同じです。

【通知の使い方】
  1. 画面の一番下の「通知欄に残り時間と進行度を表示する」にチェックを入れます。
  2. 許可の確認が出たら「許可」を押します（拒否した場合は、画面に直し方が出ます）。
  3. スタートすると、通知欄に「計測中 残り 18:42」と色ブロックの進行度が出ます。
     通知を下へ広げると、バー（20目盛り）の画像が出ます。
  4. 通知をタップすると、タイマーのページが開きます。
  ・一時停止、再開、リセット、終了にあわせて、同じ通知が書き換わります（増えません）。
  ・終了すると「時間です」の通知が、音と振動つきで出ます。
  ・通知をスワイプで消すと、次の操作（スタート・一時停止など）までは出し直しません。
  ・「通知を試す」ボタンで、今の状態の通知をすぐ確認できます。

【Androidの制限（重要）】
  ・通知の残り時間は、Androidが画面外のページの動きを制限するため、毎秒は更新できません。
    他のアプリを使っている間は、残り2分超は約15秒おき、残り2分以下は約5秒おきに更新します。
    そのため、通知の「残り」は最大で十数秒古いことがあります。通知には「終了予定 16:25」の時刻も出るので、
    そちらは常に正確です。
  ・長い時間、画面を消したままにすると、Androidがページを止めて、通知の更新や終了通知が出ないことがあります。
    その場合は、アプリを開くと残り時間と「時間です」が正しく表示されます。
    確実に終了を知らせたい場合は、スマホのアラームも併用してください。
  ・Chromeの省電力設定で「制限なし」にしておくと、更新が遅れにくくなります（任意）。
