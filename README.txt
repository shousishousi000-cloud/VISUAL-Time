ビジュアルタイマー スマホ版（Android）

【1】このフォルダの中身を、無料のウェブ公開サービスに置きます（どちらか一つでOK）
  A. Netlify Drop … https://app.netlify.com/drop を開き、このフォルダ(ファイル全部)をドラッグ＆ドロップ。
     アカウント登録すると公開が残ります。表示されたURLがタイマーのアドレスです。
  B. GitHub Pages … GitHubで新しいリポジトリを作り、ファイル全部をアップロード。
     Settings → Pages → Branch を main / (root) にして保存。表示されたURLがタイマーのアドレスです。

【2】Androidで入れる
  Chromeで上のURLを開く → 右上「︙」 → 「アプリをインストール」（または「ホーム画面に追加」）。
  ホーム画面のアイコンから、アプリのように全画面で起動できます。一度開けば、電波がなくても動きます。

【3】注意
  ・スタート中は、画面が消えないようにします。他のアプリに切り替えたり画面を閉じたりしている間は、音が鳴らないことがあります。
    終了時は、画面を開いたときに「時間です」と表示され、振動で知らせます。
  ・設定（時間・色・ダークなど）は、スマホのブラウザに保存されます。
  ・小窓モードはパソコン専用のため、スマホでは表示されません。
  ・ファイルを更新したら、同じ場所に上書きして公開し直してください。
